# Lumo ✨

Lumo is a modern productivity and personal assistant web application built with ASP.NET Core MVC.

It helps users manage tasks, plan their day, and stay focused with a clean and minimal interface.

## 🚀 Features
- Task management
- Daily planning
- Simple and intuitive UI

## 🛠️ Tech Stack
- ASP.NET Core MVC
- C#
- HTML, CSS, JavaScript
